$ sentinel — Launch interactive Oracle session
# Capabilities
🔍

SAST Scanner

30 detection rules for secrets, unsafe code, network exfiltration, env leaks. Scans local files and PR diffs.

🛡️

Supply Chain Shield

Audit npm packages before installing. Detects typosquatting, embedded credentials, malicious patterns in tarballs.

🧠

AI Oracle

Multi-provider AI assistant (Gemini, Claude, OpenAI, Ollama). 18 tools, plan/execute/auto modes, 3-layer anti-injection.

🔗

SecuriGit — GitHub Security

List PRs, view diffs, post security comments, scan PR code. Uses your existing gh authentication — no extra tokens.

📋

Threat Intelligence

Local SQLite database correlates findings by author, pattern, and signature. Learns from every scan you run.

👷

Specialized Agents

Blue Team (defense), Red Team (offensive), Auditor (compliance). Switch with /agent set.

🔐

Integrity Verification

Checks code hash, PATH poisoning, vault integrity, clock anomalies, and persistent integrity chain.

📊

Reports & Audit

Export findings as Markdown or JSON. Local audit dashboard shows rules, threats, permissions, and system health.

🌐

MCP Protocol

Model Context Protocol server lets Claude Desktop, Cursor, Cline and other AI tools query Sentinel directly.
