Step-by-step: Creating the GitHub App
Field What to put
GitHub App name Any name, e.g. sentinel-oracle
Homepage URL Your server URL: https://your-server.ts.net
(the same URL without /api/webhook/github)
Callback URL Leave blank — Sentinel Oracle does not use OAuth
Expire user tokens Unchecked — not needed
Request OAuth during install Unchecked — App uses installation tokens, not user auth
Enable device flow Unchecked — not needed
Post-installation URL Leave blank
Webhook Active — set URL to https://your-server.ts.net/api/webhook/github
Requires Tailscale — this is your Tailscale Funnel address
Webhook secret Optional — you will set it in step 3 of this wizard
Repository Permissions Required
Permission Level Purpose
Pull requests Read & Write List PRs, view changes, merge approved PRs
Checks Read & Write Create and update check runs (Sentinel review status)
Contents Read-only Read repo metadata, commits, branch protection
Metadata Read-only Repo lookup (auto-granted by GitHub)
Subscribe to Events
Event Purpose
Pull requests Detect new PRs, updates, and unauthorized merges
Push Detect pushes to main/master that bypass Oracle

After creating the App, install it on your repository. You will get the App ID (top of the App page), Installation ID (from the URL when you click Install), and download the private key (.pem file).
